# Requests from U0.07

## R1 — `packages/git` needs `CanonicalPath` and `FileTouch`, and may import neither (DESIGN 5 vs 1.1)

- **Where:** DESIGN §5 (`GitPort` uses `CanonicalPath`, defined in `@cohorte/security/contract`, and `FileTouch`, defined in
  `@cohorte/protocol`) against DESIGN 1.1 / `layers.json` (`@cohorte/git` -> `base` only).
- **What U0.07 did:** `packages/git/src/contract.ts` declares both, structurally identical to the originals
  (`Brand<string, 'CanonicalPath'>`; the five fields of `FileTouch`). Same brand string, same fields: values cross
  between `security`, `protocol` and `git` without a cast (`core` is the only place where they meet).
- **Proposed change (integrator, optional):** move `CanonicalPath` to `@cohorte/base` and re-export it from `security`
  and `git`; nothing breaks if it is left as is.
- **Affects:** U1.05 (imports both from `@cohorte/git/contract`), U0.08 (`core` ports).

## R2 — the `OS_INJECTED_ENV` mirror test has no legal import edge

- **Where:** PLAN U0.07 test "`OS_INJECTED_ENV` equals the mirror exported by `@cohorte/runtime-pi/host-protocol`";
  `layers.json` has no `security -> runtime-pi` edge, not even a `dev` one, so `check-layers` rule a would refuse the
  import from `packages/security/test/**`.
- **What U0.07 did:** `packages/security/test/contract/builtin.test.ts` loads `packages/runtime-pi/src/protocol.ts`
  by FILE URL (a computed specifier: invisible to rules a-d, legal in test code) and compares the two values.
- **Proposed change (integrator, optional):** a `dev` edge `security -> runtime-pi` and a plain import; or leave it.

## R3 — a third trigger of the silent Biome stack overflow (see `U0.02.md` R1, `U0.03.md` R1)

- **Trigger C — a `Promise<Static<...>>` that Biome has to resolve.** A test implementing the `TrustStore` port
  (`lookup(): Promise<TrustRecord | undefined>`) crashed Biome as long as `TrustRecord` was `Static<typeof TrustRecord>`;
  binding the awaited values to names did not help. Remedy: the type is written by hand and the schema const is annotated
  (`export const TrustRecord: TUnsafe<TrustRecord> = Type.Unsafe<TrustRecord>(...)`). U0.07 uses that form for EVERY `[S]`
  type that can travel through a promise or a port (`CohorteConfig`, `Ownership`, `Spec`, `CommandRule`, `TrustRecord`,
  `PolicyVerdict`, `AgentGrant`, `SandboxCapabilities`, `ProjectModel`, `DriftReport`, `ReconcilePlan`), which is also
  what keeps DESIGN's TypeScript verbatim.
- The crash still exits 0. U0.07 verified its lint by the `Checked <n> files` line, not by the exit code.
